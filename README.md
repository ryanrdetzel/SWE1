# SWE1

A SWE1 usually handles entry level engineering work. Typical duties include:

• Fixing small to medium bugs.
• Adding minor features under guidance.
• Writing clear, simple code that follows team standards.
• Creating and updating tests.
• Reviewing low risk pull requests and learning from reviews on their own work.
• Following established designs rather than creating them.
• Learning the codebase, tools, and deployment process.
• Working with a mentor or senior engineer to break down tasks and plan next steps.

The role is mainly about building core skills, delivering reliable work, and becoming a trusted part of the team.
